La plataforma CYM Ingenieros combina una landing pública en Angular 20 con un backend en NestJS que integra Dynamics 365, Microsoft Graph (OneDrive) y modelos de lenguaje vía Groq para capturar leads, generar pedidos y publicar catálogos de productos Microsoft.

- `cym-ingenieros/landing` — Aplicación Angular 20 con SSR desplegada en Vercel.
- `cym-ingenieros/backend` — API NestJS 11 con Drizzle ORM sobre PostgreSQL.
